# 大字顯示

這份 README 另有 [English](README.md) 和 [簡體中文](README-sc.md) 版本。

大字顯示是一個 Android 應用程式，能把簡短訊息變成粗體、佔滿整個螢幕的大字，讓人一眼就看得清楚。
不論是臨時做一個指示牌、在活動現場做提示，還是任何想隔著一段距離都看得見的內容，都很合用。

## 功能

- 📱 手機平板皆宜：螢幕較細或較大都一樣好看
- 📝 即時顯示：輸入或貼上文字，幾秒內就能呈現在螢幕上
- 🎨 自由配色：文字和背景顏色都能按當下需要調校
- 🔤 多款字型：內置多款字型任你挑選
- 🇭🇰🇹🇼 中文字型：收錄不少香港和台灣設計師製作的字型
- ↔️ 對齊任擺：左上、上、右上，到左、置中、右，再到左下、下、右下都可以
- 📏 字型大小：可交由系統自動調校，也可改用自訂大小，再在顯示畫面上下滑動微調
- ✨ 動態效果：備有閃爍、脈衝、交叉閃爍、交叉脈衝等效果，想突出重點時就派上用場
- 📤 分享：可把訊息做成橫向、直向或正方形圖片再分享出去
- 📨 由其他程式傳入：在其他地方選「分享」，就能把文字送進來即時顯示
- 🕘 歷史記錄：之前用過的設定可取回再用，或直接再顯示一次
- 🌐 多語言：英文、繁體中文、簡體中文隨時切換
- 🌙 看得舒服：主畫面可切換淺色或深色模式

## 快速上手

### 系統需求

- `Node.js` 22.11 或以上
- 已設定好 React Native 的 Android 開發環境
- 一部 Android 裝置或模擬器
- iOS 暫未支援

### 安裝依賴

```sh
npm install
```

### 啟動 Metro

```sh
npm start
```

### 在 Android 上執行

```sh
npm run android
```

如果你接駁了實體 Android 裝置，這個 repository 也預備了一個方便你使用的腳本：

```sh
npm run android:physical
```

### 常用指令

```sh
npm run lint
npm test
```

## 備註

- 這個應用程式目前主要針對 Android 的行為，例如全螢幕沉浸模式、顯示期間保持螢幕長亮，以及靠感應器自動旋轉。
- 字型資源已一併打包進應用程式，所以安裝後字型清單即可使用。

## 一般用法

1. 開啟應用程式。
2. 在主畫面輸入文字。
3. 選擇文字顏色、背景顏色、字型、字型大小、對齊和效果。
4. 按「顯示」，文字便會全螢幕呈現。
5. 想取回之前的設定來用或將它刪去，就進入「歷史」。

## 專案指令

- `npm start`：啟動 Metro。
- `npm run android`：建置後在 Android 開啟應用程式。
- `npm run android:physical`：安裝到已接駁的實體 Android 裝置。
- `npm run lint`：執行 ESLint。
- `npm test`：執行 Jest。
