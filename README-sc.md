# 大字显示

这份 README 另有 [English](README.md) 和 [繁體中文](README-tc.md) 版本。

大字显示是一个 Android 应用程式，能把简短讯息变成粗体、占满整个萤幕的大字，让人一眼就看得清楚。
不论是临时做一个指示牌、在活动现场做提示，还是任何想隔著一段距离都看得见的内容，都很合用。

## 功能

- 📱 手机平板皆宜：萤幕较小或较大都一样好看
- 📝 即时显示：输入或贴上文字，几秒内就能呈现在萤幕上
- 🎨 自由配色：文字和背景颜色都能按当下需要调校
- 🔤 多款字体：内置多款中文及英文字体任你挑选
- ↔️ 对齐任摆：左上、上、右上，到左、居中、右，再到左下、下、右下都可以
- 📏 字体大小：可交由系统自动调校，也可改用自定义大小，再在显示画面上下滑动微调
- ✨ 动态效果：备有闪烁、脉冲、交叉闪烁、交叉脉冲等效果，想突出重点时就派上用场
- 📤 分享：可把讯息做成横向、直向或正方形图片再分享出去
- 📨 由其他程式传入：在其他地方选「分享」，就能把文字送进来即时显示
- 🕘 历史记录：之前用过的设定可取回再用，或直接再显示一次
- 🌐 多语言：英文、繁体中文、简体中文随时切换
- 🌙 看得舒服：主画面可切换浅色或深色模式

## 快速上手

### 系统需求

- `Node.js` 22.11 或以上
- 已设定好 React Native 的 Android 开发环境
- 一部 Android 装置或模拟器
- iOS 暂未支援

### 安装依赖

```sh
npm install
```

### 启动 Metro

```sh
npm start
```

### 在 Android 上执行

```sh
npm run android
```

如果你接驳了实体 Android 装置，这个 repository 也预备了一个方便你使用的脚本：

```sh
npm run android:physical
```

### 常用指令

```sh
npm run lint
npm test
```

## 备注

- 这个应用程式目前主要针对 Android 的行为，例如全萤幕沉浸模式、显示期间保持萤幕长亮，以及靠感应器自动旋转。
- 字体资源已一并打包进应用程式，所以安装后字体清单即可使用。

## 一般用法

1. 开启应用程式。
2. 在主画面输入文字。
3. 选择文字颜色、背景颜色、字体、字体大小、对齐和效果。
4. 按「显示」，文字便会全萤幕呈现。
5. 想取回之前的设定来用或将它删去，就进入「历史」。

## 专案指令

- `npm start`：启动 Metro。
- `npm run android`：建置后在 Android 开启应用程式。
- `npm run android:physical`：安装到已接驳的实体 Android 装置。
- `npm run lint`：执行 ESLint。
- `npm test`：执行 Jest。
